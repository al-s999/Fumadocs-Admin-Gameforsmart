# Pengenalan Portal Admin GameForSmart

Selamat datang di **Portal Administrator GameForSmart**. Portal ini adalah pusat kendali operasional terpadu yang dirancang untuk mendukung kelancaran ekosistem permainan cerdas cermat interaktif GameForSmart.

Sebagai staf administrator, Anda memegang peranan penting dalam memastikan konten kuis berkualitas tinggi, room permainan berjalan stabil, turnamen sekolah terlaksana dengan tertib, dan kendala pengguna tertangani secara profesional.

---

## Ekosistem Game yang Dikelola

Melalui portal ini, Anda mengawasi operasional 7 platform game multiplayer dengan mekanik yang beragam:

| Nama Game | Genre & Mekanik Utama | Target Pembelajaran |
| :--- | :--- | :--- |
| **SpaceQuiz** | Trivia & Petualangan Angkasa | Ketangkasan reflek sambil menjawab kuis sains |
| **MemoryQuiz** | Teka-Teki & Pencocokan Kartu | Pelatihan daya ingat visual dan konsep materi |
| **CrazyRace** | Balapan Cepat & Cerdas Cermat | Kecepatan menjawab soal di lintasan balap |
| **QuizRush** | Aksi Ritme & Uji Kecepatan | Ketepatan respon cepat dalam batas waktu singkat |
| **NitroQuiz** | Adu Cepat Antar-Pemain (*Nitro*) | Persaingan kompetitif dengan pemicu booster nilai |
| **Zigma** | Petualangan RPG & Sistem Tim | Kerja sama tim, pertarungan raid boss kuis |
| **Axiom** | Penalaran Logika & Pemecahan Masalah | Soal-soal analitis matematika dan sains |

## Persyaratan Penggunaan

Untuk kenyamanan dan efisiensi kerja operasional harian, pastikan Anda menggunakan:

*   **Perangkat**: Komputer atau laptop dengan resolusi layar minimal `1280 x 720` piksel (disarankan `1920 x 1080` piksel) agar tampilan tabel data tersaji optimal.
*   **Peramban Web Modern**: Disarankan menggunakan **Google Chrome**, **Mozilla Firefox**, **Microsoft Edge**, atau **Safari** versi terbaru.
*   **Kamera Web (Webcam)**: Diperlukan khusus bagi staf yang bertugas di meja resepsionis turnamen luring untuk memindai tiket kode QR peserta.
*   **Koneksi Internet**: Koneksi internet stabil untuk menerima pembaruan data secara langsung (*real-time*).

<Callout type="info">
  Portal Admin dirancang berbasis web penuh (*web-based*). Anda tidak perlu memasang aplikasi tambahan apa pun di komputer Anda. Cukup buka peramban dan masuk ke alamat resmi portal.
</Callout>
