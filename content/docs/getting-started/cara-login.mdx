# Cara Masuk

Halaman ini memuat panduan masuk ke akun admin GameForSmart, mekanisme proteksi akun, serta tata cara keluar sesi.

---

## 1. Alamat Resmi Website

*   Pastikan URL di bilah peramban diawali dengan protokol aman `https://`.
*   Hindari memasukkan data kredensial admin pada situs pihak ketiga atau tautan yang mencurigakan.

---

## 2. Langkah Masuk (Login)

1.  **Buka Halaman Login**: Akses halaman login resmi admin GameForSmart.
2.  **Masukkan Identitas Akun**: Ketikkan alamat email atau username yang telah didaftarkan.
3.  **Masukkan Kata Sandi**: Masukkan kata sandi akun Anda.
4.  **Verifikasi Keamanan**: Selesaikan verifikasi reCAPTCHA.
5.  **Klik Login**: Sistem akan memvalidasi akun dan mengarahkan Anda ke dashboard kerja sesuai peran.

---

## 3. Proteksi Percobaan Masuk

*   **Batas Salah Input**: Akun terkunci otomatis jika salah memasukkan kata sandi sebanyak 3 kali berturut-turut.
*   **Pencegahan Brute-Force**: Percobaan login salah berulang akan dibatasi sementara oleh firewall sistem.
*   **Log Akses**: Setiap aktivitas login berhasil maupun gagal dicatat otomatis di log audit.
*   **Bantuan Akun Terkunci**: Jika akun terkunci, hubungi Superadmin untuk verifikasi dan pembukaan blokir.

---

## 4. Cara Keluar (Logout)

1.  Klik **Menu Profil (Avatar)** di sudut kanan atas layar.
2.  Pilih opsi **Logout**.
3.  Konfirmasi pada kotak dialog yang muncul untuk mengakhiri sesi kerja secara aman.
