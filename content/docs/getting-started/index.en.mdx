# GameForSmart Admin Dashboard

Welcome to the **GameForSmart Admin Dashboard**. This dashboard is the unified operational command center designed to support the smooth operation of GameForSmart's interactive quiz game ecosystem.

As an administrator staff member, you play a vital role in ensuring high-quality quiz content, stable game rooms, orderly school tournaments, and professionally resolved user issues.

---

## Managed Game Ecosystem

Through this dashboard, you oversee the operations of multiplayer game platforms with diverse mechanics:

| Game Name | Genre & Core Mechanics |
| :--- | :--- |
| **SpaceQuiz** | Trivia & Space Adventure |
| **MemoryQuiz** | Puzzles & Card Matching |
| **CrazyRace** | Fast Racing & Trivia Speed |
| **QuizRush** | Rhythm Action & Speed Challenge |
| **NitroQuiz** | Player-vs-Player Speed Contest (*Nitro*) |
| **Zigma** | RPG Adventure & Team System |
| **Axiom** | Logic Reasoning & Problem Solving |
