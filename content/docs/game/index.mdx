# Dashboard Game

Halaman **Dashboard Game** (`/game/dashboard`) menyajikan ringkasan analitik komprehensif terkait seluruh judul permainan interaktif di dalam ekosistem GameForSmart.

---

## 1. Kartu Statistik Game

Di baris teratas, Anda akan menemukan informasi rangkuman:
*   **Total Judul Game Terdaftar**: Jumlah game yang terhubung dalam sistem.
*   **Game Aktif (*Online*)**: Jumlah game yang siap dimainkan oleh publik tanpa kendala pemeliharaan.
*   **Game Dalam Pemeliharaan (*Maintenance*)**: Jumlah game yang sedang dinonaktifkan sementara untuk perbaikan bug atau pembaruan konten.
*   **Total Jam Bermain Hari Ini**: Akumulasi durasi seluruh sesi room yang dimainkan oleh pengguna hari ini.

---

## 2. Grafik Sesi Game

Grafik ini memperlihatkan volume room game yang dibuat oleh para guru dan host sepanjang hari:
*   **Pola Jam Sibuk (*Peak Hours*)**: Umumnya lonjakan terjadi pada jam sekolah pukul 08.00–12.00 dan sore hari pukul 15.00–18.00.
*   **Deteksi Anomali**: Jika terjadi penurunan tajam pada hari aktif sekolah, segera periksa status server atau koneksi pihak ketiga.
