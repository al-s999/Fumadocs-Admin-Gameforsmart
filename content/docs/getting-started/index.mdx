# Dashboard Admin GameForSmart

Selamat datang di **Dashboard Admin GameForSmart**. Dashboard ini merupakan pusat kendali operasional terpadu untuk mengelola konten kuis, room permainan, turnamen, dan layanan bantuan pengguna.

---

## 1. Ekosistem Game yang Dikelola

Platform mengawasi 7 permainan cerdas cermat interaktif:
*   **SpaceQuiz**: Trivia eksplorasi antariksa.
*   **MemoryQuiz**: Uji memori dan pencocokan kartu edukasi.
*   **CrazyRace**: Balapan cepat berbasis cerdas cermat.
*   **QuizRush**: Kuis eliminasi cepat berpacu dengan ritme musik.
*   **NitroQuiz**: Adu cepat menjawab dengan pengali poin (*booster*).
*   **Zigma**: Petualangan RPG dan kolaborasi regu tim.
*   **Axiom**: Pemecahan masalah logika, sains, dan matematika HOTS.

---

## 2. Tanggung Jawab Operasional Staf

*   **Kurasi Kuis**: Memeriksa mutu dan kelayakan soal kiriman komunitas/guru sebelum terbit publik.
*   **Pengawasan Room Game**: Memantau kestabilan room aktif dan melakukan intervensi darurat jika terjadi gangguan.
*   **Manajemen Turnamen**: Mengatur jadwal perlombaan, whitelist peserta, dan memantau klasemen juara.
*   **Pusat Bantuan**: Merespons tiket keluhan pengguna, memverifikasi pembayaran, dan menindaklanjuti laporan pelanggaran.
