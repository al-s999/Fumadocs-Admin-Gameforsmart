# Kelola Games

Halaman **Kelola Game** (`/manage-games`) memberikan wewenang kepada staf administrator untuk mengatur parameter operasional dan tautan server dari setiap permainan.

---

## 1. Parameter Tabel Game

*   **Judul & Slug**: Nama resmi dan pengenal unik permainan di sistem.
*   **Play URL**: Alamat URL mesin game tempat pemain terhubung saat room dibuat.
*   **Versi Rilis**: Nomor versi game yang sedang aktif (contoh: `v1.4.2`).
*   **Status Ketersediaan**: Sakelar toggle yang menentukan apakah game dapat dipilih pengguna.

---

## 2. Memperbarui Konfigurasi Game

1.  Cari game yang akan disunting pada tabel, lalu klik tombol **Sunting (Edit)**.
2.  Perbarui data yang diperlukan: **Play URL**, unggah **Poster Sampul**, atau ubah teks panduan **How to Play**.
3.  Klik tombol **Simpan Konfigurasi**. Perubahan langsung diterapkan ke aplikasi pengguna.

---

## 3. Mode Pemeliharaan (*Maintenance Mode*)

Jika sebuah game mengalami gangguan teknis atau sedang diperbarui servernya:
1.  Buka baris game terkait di halaman `/manage-games`.
2.  Geser sakelar **Status Ketersediaan** menjadi nonaktif/abu-abu.
3.  Tuliskan pesan singkat alasan pemeliharaan untuk pemain.
4.  Klik **Terapkan**. Pemain tidak dapat membuat room baru untuk game tersebut hingga status diaktifkan kembali.
