# Mengenal Tampilan & Navigasi

Antarmuka **Portal Admin GameForSmart** dirancang secara intuitif untuk mempermudah pemantauan kuis, room game, dan turnamen. Seluruh tata letak antarmuka terbagi menjadi tiga komponen utama: **Bilah Navigasi Kiri (Sidebar)**, **Bilah Atas (Header)**, dan **Area Kerja Utama (Content Area)**.

---

## 1. Anatomi Tata Letak (*Layout*)

```
┌────────────────────────────────────────────────────────────────────────┐
│  [Logo GFS]  [Toggle Sidebar]             [Lonceng] [Bantuan] [Tema] [Profil] │ <- Header
├──────────────┬─────────────────────────────────────────────────────────┤
│              │                                                         │
│  10 MENU     │  AREA KERJA UTAMA                                       │
│  NAVIGASI    │                                                         │
│  UTAMA       │  - Kartu Ringkasan Data (KPI Stats)                     │
│  (Sidebar)   │  - Tabel Data Interaktif                                │
│              │  - Kotak Filter & Pencarian                             │
│              │  - Tombol Aksi Cepat                                    │
│              │                                                         │
└──────────────┴─────────────────────────────────────────────────────────┘
```

## 2. Bilah Sisi Kiri (Sidebar): 10 Kelompok Menu Utama

Bilah navigasi kiri mengelompokkan seluruh fitur operasional ke dalam **10 menu induk**. Setiap menu dapat diklik untuk membuka sub-halaman terkait:

| No | Nama Menu Induk | Ikon & Tautan Utama | Ringkasan Fungsi Operasional |
| :-: | :--- | :--- | :--- |
| **1** | **Dashboard** | `/dashboard` | Meninjau metrik utama platform: total pengguna aktif, kuis berjalan, omzet turnamen, dan grafik aktivitas. |
| **2** | **Game** | `/game` | Memantau katalog 7 game resmi, mengontrol status pemeliharaan game, mengawasi room game aktif, dan memeriksa ulasan pemain. |
| **3** | **Quiz** | `/quiz` | Meninjau kuis komunitas (*approval*), mengelola bank soal kuis, dan mengatur templat penolakan kuis yang tidak memenuhi kriteria. |
| **4** | **Competition** | `/competition` | Membuat turnamen kuis, mengatur kategori turnamen, mengelola pendaftaran peserta, dan scanner QR meja resepsionis turnamen. |
| **5** | **Blog** | `/blog` | Mengelola publikasi artikel edukasi, berita turnamen, kategori artikel, serta memantau sesi membaca para pengunjung. |
| **6** | **Support** | `/support` | Menjawab tiket kendala pengguna, menangani laporan kecurangan/pelanggaran, memoderasi grup pemain, dan memantau sesi bantuan aktif. |
| **7** | **Billing** | `/billing` | Mengawasi arus transaksi pembayaran turnamen Xendit, metode pembayaran, rekonsiliasi keuangan, dan status paket langganan. |
| **8** | **Master Data** | `/master` | Mengelola data referensi wilayah geografis (Negara, Provinsi/State, dan Kota/City) untuk standarisasi profil pengguna. |
| **9** | **Administrator** | `/administrator` | Memoderasi profil seluruh pengguna platform, mengelola akun staf admin, dan memulihkan data yang terhapus di Tempat Sampah (*Trash Bin*). |
| **10** | **Setting** | `/settings` | Mengaktifkan mode pemeliharaan global (*Maintenance Mode*), mengatur tema visual, memperbarui profil staf, dan memeriksa log audit aktivitas. |

<Callout type="tip">
  **Menyembunyikan / Memperlebar Sidebar**: Anda dapat mengklik tombol ikon bilah di sebelah kiri atas header untuk memperkecil (*collapse*) bilah sisi menjadi hanya menampilkan ikon, sehingga area tabel data menjadi lebih luas.
</Callout>

## 3. Bilah Atas (Header) & Kontrol Cepat

Bilah atas selalu tampil di setiap halaman untuk memberikan akses ke instrumen penting berikut:

### A. Ikon Notifikasi (Lonceng)
Menampilkan indikator titik merah jika ada aktivitas baru yang membutuhkan perhatian staf. Klik ikon lonceng untuk melihat ringkasan:
*   **Laporan Baru (*New Report*)**: Laporan indikasi kecurangan atau konten tidak pantas dari pemain.
*   **Interaksi Blog (*Blog Interaction*)**: Komentar atau tanggapan baru pada artikel edukasi.
*   **Pendaftaran Pengguna Baru (*New User*)**: Pendaftaran pengguna baru yang memerlukan peninjauan.

### B. Tombol Bantuan Cepat (*Help Button*)
Ikon tanda tanya (**?**) di sebelah kanan atas berfungsi sebagai tombol panduan kontekstual. Mengklik tombol ini akan membuka dokumentasi yang relevan langsung dengan halaman yang sedang Anda buka tanpa perlu mencari manual.

### C. Sakelar Tema Tampilan (*Mode Toggle*)
Memungkinkan Anda beralih antara:
*   **Mode Terang (*Light Mode*)**: Latar belakang putih bersih yang nyaman untuk ruangan dengan pencahayaan terang.
*   **Mode Gelap (*Dark Mode*)**: Latar belakang bernuansa gelap yang mereduksi ketegangan mata saat bertugas di malam hari.

### D. Menu Profil Pengguna
Menampilkan foto profil (*avatar*) dan nama staf yang sedang bertugas. Mengklik menu ini memunculkan opsi:
*   **Profil Saya**: Memeriksa nama lengkap, surel dinas, dan peran akun Anda.
*   **Pengaturan Keamanan**: Memperbarui kata sandi dan mengelola verifikasi 2 langkah.
*   **Keluar (*Logout*)**: Mengakhiri sesi kerja operasional secara aman.

## 4. Pola Kerja di Area Utama (*Workspace*)

Hampir seluruh halaman di dalam portal admin mengikuti standar tata letak yang konsisten:

1.  **Header Halaman**: Menyajikan judul halaman, deskripsi tugas singkat, dan tombol tindakan utama (misalnya tombol *+ Tambah Kuis Baru* atau *+ Buat Turnamen*).
2.  **Bilah Pencarian & Filter Cepat**: Disediakan kolom pencarian instan dan dropdown filter (misalnya filter status: *Aktif*, *Ditangguhkan*, *Menunggu Persetujuan*).
3.  **Tabel Data Interaktif**: Menampilkan baris data dengan indikator status berwarna (hijau untuk aktif, kuning untuk menunggu, merah untuk diblokir).
4.  **Kolom Tindakan (*Action Menu*)**: Ikon titik tiga (`···`) di ujung kanan setiap baris tabel untuk melihat detail, menyunting data, atau memindahkan ke tempat sampah.
5.  **Navigasi Halaman (*Pagination*)**: Terletak di bagian bawah tabel untuk berpindah ke halaman berikutnya jika data berjumlah ratusan atau ribuan.
