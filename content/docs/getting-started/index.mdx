# Dashboard Admin GameForSmart

Selamat datang di **Dashboard Admin GameForSmart**. Dashboard ini adalah pusat kendali operasional terpadu yang dirancang untuk mendukung kelancaran ekosistem permainan cerdas cermat interaktif GameForSmart.

Sebagai staf administrator, Anda memegang peranan penting dalam memastikan konten kuis berkualitas tinggi, room permainan berjalan stabil, turnamen sekolah terlaksana dengan tertib, dan kendala pengguna tertangani secara profesional.

---

## Ekosistem Game yang Dikelola

Melalui dashboard ini, Anda mengawasi operasional platform game multiplayer dengan mekanik yang beragam:

| Nama Game | Genre & Mekanik Utama |
| :--- | :--- |
| **SpaceQuiz** | Trivia & Petualangan Angkasa |
| **MemoryQuiz** | Teka-Teki & Pencocokan Kartu |
| **CrazyRace** | Balapan Cepat & Cerdas Cermat |
| **QuizRush** | Aksi Ritme & Uji Kecepatan |
| **NitroQuiz** | Adu Cepat Antar-Pemain (*Nitro*) |
| **Zigma** | Petualangan RPG & Sistem Tim |
| **Axiom** | Penalaran Logika & Pemecahan Masalah |
