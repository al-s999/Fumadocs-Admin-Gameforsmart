# Mengenal Tampilan & Navigasi

Antarmuka Dashboard Admin GameForSmart terbagi menjadi tiga komponen utama: **Bilah Navigasi Kiri (Sidebar)**, **Bilah Atas (Header)**, dan **Area Kerja Utama**.

---

## 1. Anatomi Tata Letak (*Layout*)

```
┌───────────────────────────────────────────────────────────┐
│ [Logo] [Toggle]               [Notifikasi] [Tema] [Profil]│ <- Header
├─────────────┬─────────────────────────────────────────────┤
│ 10 MENU     │ AREA KERJA UTAMA                            │
│ NAVIGASI    │ - Kartu Ringkasan Metrik (KPI)              │
│ (Sidebar)   │ - Tabel Data & Tombol Aksi                  │
│             │ - Kotak Pencarian & Filter Cepat            │
└─────────────┴─────────────────────────────────────────────┘
```

---

## 2. 10 Kelompok Menu Navigasi

| Menu | Tautan | Fungsi Utama |
| :--- | :--- | :--- |
| **Dashboard** | `/dashboard` | Ringkasan metrik pengguna, kuis berjalan, dan grafik aktivitas. |
| **Game** | `/game` | Monitoring 7 game resmi, room aktif, status pemeliharaan, dan ulasan. |
| **Quiz** | `/quiz` | Kurasi kuis komunitas, manajemen bank soal, dan templat penolakan. |
| **Competition** | `/competition` | Pembuatan turnamen, babak eliminasi, whitelist, dan scanner QR resepsionis. |
| **Blog** | `/blog` | Pengelolaan artikel edukasi, berita kompetisi, dan analisis durasi baca. |
| **Support** | `/support` | Penanganan tiket keluhan, laporan pelanggaran, sesi aktif, dan moderasi grup. |
| **Billing** | `/billing` | Monitoring transaksi invoice Xendit, metode pembayaran, dan rekonsiliasi. |
| **Master Data** | `/master` | Standarisasi hierarki data wilayah geografis (Negara, Provinsi, Kota). |
| **Administrator** | `/administrator` | Manajemen profil pengguna, peran akun staf, dan tempat sampah data. |
| **Settings** | `/settings` | Mode pemeliharaan sistem, keamanan akun, dan log audit operasional. |

---

## 3. Kontrol Bilah Atas (Header)

*   **Notifikasi (Lonceng)**: Menampilkan pemberitahuan laporan baru, kuis masuk, dan pendaftaran pengguna.
*   **Bantuan Cepat (?)**: Membuka dokumen panduan yang relevan langsung dengan halaman yang sedang dibuka.
*   **Ganti Tema**: Mengalihkan mode tampilan antara Terang (*Light*) dan Gelap (*Dark*).
*   **Profil Staf**: Mengakses profil, pengaturan keamanan kata sandi/2FA, dan tombol keluar (*Logout*).

---

## 4. Standar Area Kerja (*Workspace*)

*   **Header Halaman**: Judul halaman, deskripsi tugas, dan tombol aksi utama.
*   **Pencarian & Filter**: Kolom pencarian instan dan filter status data.
*   **Tabel Data**: Menampilkan baris data dilengkapi indikator status.
*   **Menu Tindakan (`···`)**: Pilihan untuk melihat rincian, menyunting, atau menghapus data.
*   **Paginasi**: Navigasi halaman di bagian bawah tabel untuk volume data besar.
