# Role dan Aksesnya

Admin GameForSmart menerapkan prinsip pembagian wewenang berdasarkan Role (*Role-Based Access Control* / RBAC). Sistem ini memastikan setiap staf hanya dapat mengakses fitur dan data yang sesuai dengan tanggung jawab tugasnya masing-masing.

---

## 1. Role

Di dalam ekosistem GameForSmart, akun staf terbagi menjadi 4 kategori wewenang utama:

### A. Superadmin (`super_admin`)
*   **Kedudukan**: Pemegang otoritas tertinggi sistem.
*   **Tanggung Jawab**:
    *   Mengatur konfigurasi global aplikasi dan mengaktifkan mode pemeliharaan (*Maintenance Mode*).
    *   Membuat akun staf baru dan menetapkan tingkatan Role masing-masing staf.
    *   Memulihkan data atau melakukan penghapusan data secara permanen dari Tempat Sampah (*Trash Bin*).
    *   Mengakses seluruh menu tanpa batasan.

### B. Admin Layanan & Operasional (`admin_support`)
*   **Kedudukan**: Staf inti pemantauan konten kuis, komunitas, dan bantuan pengguna.
*   **Tanggung Jawab**:
    *   Meninjau, menyetujui (*approve*), atau menolak (*reject*) kuis yang diajukan komunitas atau guru.
    *   Mengawasi room game yang sedang berjalan dan menangani room yang bermasalah.
    *   Memoderasi akun pengguna, menertibkan nama pengguna yang melanggar norma, dan menindaklanjuti laporan pelanggaran.
    *   Membalas tiket keluhan dari pengguna melalui Pusat Bantuan.

### C. Admin Keuangan & Transaksi (`admin_billing`)
*   **Kedudukan**: Staf khusus pengawasan transaksi dan rekonsiliasi pembayaran.
*   **Tanggung Jawab**:
    *   Memantau status transaksi pembayaran turnamen melalui gateway pembayaran Xendit.
    *   Memverifikasi bukti pembayaran pendaftaran turnamen jika terjadi kendala verifikasi otomatis.
    *   Meninjau rekonsiliasi arus kas dan riwayat pengembalian dana (*refund*).
    *   Memantau perkembangan modul paket langganan berbayar.

## 2. Akses Setiap Role

Tabel berikut merangkum wewenang masing-masing peran terhadap kelompok menu navigasi utama:

| Kelompok Menu Utama | Superadmin | Admin Support | Admin Billing |
| :--- | :---: | :---: | :---: |
| **Dashboard** | Penuh | Penuh | Ringkasan Billing |
| **Game** | Penuh | Penuh | Hanya Lihat |
| **Quiz** | Penuh | Penuh | - |
| **Competition** | Penuh | Penuh | Hanya Lihat Biaya |
| **Blog** | Penuh | Penuh | - |
| **Support & Laporan** | Penuh | Penuh | - |
| **Billing & Transaksi** | Penuh | Hanya Status | Penuh |
| **Master Data** | Penuh | Hanya Lihat | - |
| **Administrator & User** | Penuh | Moderasi Profil | - |
| **Setting & Trash Bin** | Penuh | - | - |

*Keterangan simbol:*
*   **Penuh**: Berhak melihat, membuat, mengubah, dan memindahkan ke tempat sampah.
*   **Hanya Lihat**: Hanya dapat membaca data tanpa tombol ubah/hapus.
*   **-**: Menu tidak tampil di bilah navigasi staf.
