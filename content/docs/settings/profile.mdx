# Profil Admin

Halaman **Profil Admin** (`/settings/profile`) digunakan untuk mengelola data identitas diri staf yang sedang aktif bertugas.

---

## 1. Komponen Data Profil Admin

Pada lembar profil, Anda dapat melihat dan memperbarui:
*   **Foto Avatar (*Profile Picture*)**: Unggah foto resmi diri Anda (format JPG/PNG dengan rasio 1:1 persegi). Avatar ini akan tampil di sudut kanan atas header serta di samping pesan tiket bantuan yang Anda kirimkan kepada pengguna.
*   **Nama Lengkap (*Full Name*)**: Nama lengkap staf untuk kepentingan formal dan tanda tangan digital balasan tiket.
*   **Nama Pengguna (*Username*)**: Nama panggil akun unik yang digunakan saat proses login.
*   **Alamat Surel Dinas (*Email*)**: Alamat email resmi tempat menerima notifikasi laporan darurat dan tautan pemulihan kata sandi.
*   **Peran Akun (*Role Badge*)**: Menampilkan label peran resmi Anda (`Super Admin`, `Admin Support`, `Admin Billing`, dll.). Label peran ini hanya dapat diubah oleh Superadmin.

---

## 2. Langkah Memperbarui Profil

1.  Buka `/settings/profile`.
2.  Ubah kolom nama lengkap atau klik tombol **Ganti Foto** untuk memilih berkas avatar baru dari komputer Anda.
3.  Tekan tombol **Simpan Pembaruan Profil**. Data identitas Anda akan seketika diperbarui di seluruh panel antarmuka.
