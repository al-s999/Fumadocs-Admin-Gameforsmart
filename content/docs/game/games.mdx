# Katalog Game

Halaman **Katalog Game** (`/games`) menyajikan etalase informasi resmi mengenai 7 game cerdas cermat multiplayer di platform GameForSmart.

---

## 1. Daftar 7 Game Resmi

*   **SpaceQuiz**: Trivia antariksa. Jawaban tepat menambah energi pelindung kapal ruang angkasa untuk melewati asteroid.
*   **MemoryQuiz**: Pencocokan kartu berpasangan untuk melatih daya ingat visual dan terminologi ilmiah.
*   **CrazyRace**: Balapan mobil cerdas cermat. Kecepatan dan ketepatan jawaban menentukan laju kendaraan di sirkuit.
*   **QuizRush**: Kuis eliminasi cepat berpacu dengan batas waktu tempo ketukan musik.
*   **NitroQuiz**: Kuis adu cepat dengan pemicu *Nitro Booster* untuk melipatgandakan poin jawaban.
*   **Zigma**: Petualangan RPG regu tim (*party*) yang mengumpulkan energi kuis untuk menaklukkan bos monster.
*   **Axiom**: Platform kuis logika analitis dengan papan corat-coret digital untuk soal HOTS.

---

## 2. Parameter Kartu Katalog

Setiap kartu game memuat informasi:
*   **Banner Game**: Grafis identitas visual resmi game.
*   **Play URL**: Alamat URL mesin permainan tempat client terhubung.
*   **Badge Status**: Indikator operasional (`Aktif` atau `Maintenance`).
*   **How to Play**: Panduan ringkas aturan main bagi peserta.
