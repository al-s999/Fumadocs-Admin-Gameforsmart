# Tampilan

Halaman **Tampilan** (`/appearance`) memungkinkan staf administrator menyesuaikan estetika antarmuka kerja portal admin agar memberikan kenyamanan visual terbaik sesuai preferensi masing-masing operator.

---

## 1. Pilihan Mode Tema Layar

Anda dapat memilih salah satu dari 3 opsi tema:
*   **Mode Terang (*Light Mode*)**: Latar belakang putih bersih dengan teks kontras gelap. Ideal untuk ruangan kerja dengan pencahayaan lampu terang atau sinar matahari.
*   **Mode Gelap (*Dark Mode*)**: Latar belakang abu-abu gelap dengan teks kontras lembut. Merelaksasi mata saat bertugas memantau turnamen di malam hari atau dalam pencahayaan redup.
*   **Mengikuti Sistem (*System Default*)**: Tema portal akan secara otomatis menyesuaikan dengan pengaturan mode gelap/terang pada sistem operasi komputer Anda (Windows/macOS).

---

## 2. Kustomisasi Radius Sudut Elemen (*Corner Radius*)

Untuk kenyamanan tata letak, Anda dapat mengatur tingkat kebulatan sudut tombol dan kartu data:
*   `0.3` (Gaya Tegas / Tajam)
*   `0.5` (Standar GameForSmart Modern)
*   `0.75` / `1.0` (Gaya Membulat Lembut)

Pilihan tampilan ini disimpan secara lokal di peramban Anda dan tidak memengaruhi tampilan admin lain.
